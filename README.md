# MicroWakeWord

A lightweight repository for experimenting with and building a small wake-word detection pipeline for edge devices and resource-constrained environments.

This project is a personal endeavor for my devices if it can be of use to someone, Great!

## Project goals

- My Kaggle notebook.
    - Super Efficient. Runs on Kaggle.
    - Notes are in the Book, however you probably just want to change Word Variant.
    - Parameters are optimized for a mid noise level wake with variants around the name.
    - A few clever tricks to create a professional level model with reduced times.
    - It loads its own needed python environment to avoid patching.
    - Run it with Internet ON and T4 settings.
 
- Micro WakeWords
    - There are two wake words here generated by the Kaggle Model above
    - My Genie And Esmeraldad
    - Feel free to use them.
    - The words have been successfully tested on HA PE and Androids
